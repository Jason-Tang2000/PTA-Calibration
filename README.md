# PTA-Calibration
Pure tone audiometry is the most common hearing measurement method. To evaluate and compare the result of OAE measurement, we create our own PTA system followed medical protocal. For the measurement accuracy, headphone calibration system is needed.

RETSPL is the number of dB SPL that you would expect with that coupler/headphone combination for 0 dB HL.
So if we know that 0dB HL at 1kHz corresponds to 7.5 dB SPL, thus for a dial reading of 70 dB HL we would expect 77.5 dB SPL.

Procedure
1.	Set up equipment.
2.	Set the sound level meter (SLM, an IEC artificial ear) to dB(Z) or linear frequency response.
3.	Check the sensitivity of the SLM using a sound level calibrator.
4.	Set the audiometer to 70 dB HL (60 dB HL is also possible, but expected values must be adjusted accordingly).
5.	Listen to the audiometer output to ensure the signal is appropriate.
6.	Place the earphone centrally on the coupler with a 4.5 N force applied.
7.	Measure the sound level using the SLM.
8.	Compare the measured reading with the expected values (RETSPL Table).
9.	Change the frequency and repeat the measurements (repeat for the other earphone).
10.	If readings differ by more than 3.7 dB (125 Hz–4 kHz; or 6.2 dB up to 8 kHz, per BS EN 60645-1:2015), the audiometer requires adjustment.
